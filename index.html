Windows may say “virus” — it is a false positive

Windows può segnalare “virus” / Trojan — è un falso positivo

Italiano

L’installer beta di KERF non è ancora firmato digitalmente (il certificato ha un costo; arriverà in seguito). Windows Defender / SmartScreen possono mostrare “minaccia rilevata”, Trojan, Wacatac, o “Windows ha protetto il PC”. Non è malware — è un falso positivo tipico degli EXE non firmati in closed beta. KERF è sicuro.

  1. SmartScreen (“Windows ha protetto il PC”): clicca Ulteriori informazioni → poi Esegui comunque.
  2. Defender / quarantena: apri Sicurezza di Windows → Cronologia protezione → seleziona il file KERF → Consenti nel dispositivo (o Ripristina).

Non disattivare Windows Defender in modo permanente. Basta consentire solo questo installer KERF.

English

The KERF beta installer is not code-signed yet (signing cert costs money; planned later). Windows Defender / SmartScreen may show “threat detected”, Trojan, Wacatac, or “Windows protected your PC”. This is not malware — a false positive on unsigned closed-beta EXEs. KERF is safe.

  1. SmartScreen (“Windows protected your PC”): click More info → then Run anyway.
  2. Defender quarantine: open Windows Security → Protection history → select the KERF file → Allow on device (or Restore).

Do not turn Windows Defender off permanently. Only allow this KERF installer.

Why unsigned? Closed beta — Authenticode signing comes after we buy the certificate. Technical notes
